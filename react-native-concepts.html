APIs React Native

StyleSheet

StyleSheet.create() définit les styles en dehors du render. Optimisé nativement, c'est l'équivalent du CSS-in-JS côté React Native.

const styles = StyleSheet.create({
  container: { flex: 1, backgroundColor: colors.background },
  header: { flexDirection: 'row', alignItems: 'center', padding: 16 },
});

Dimensions

Dimensions.get('window') retourne { width, height } de l'écran. Utilisé pour calculer des tailles relatives (ex: largeur des cellules Explore = width / 3 - 1).

Platform

Platform.OS retourne 'ios', 'android' ou 'web'. Utilisé pour adapter certains comportements selon l'OS (ex: KeyboardAvoidingView behavior).

const behavior = Platform.OS === 'ios' ? 'padding' : 'height';

Animated API

Système d'animation intégré à React Native. Les animations s'exécutent sur le thread natif (useNativeDriver: true) pour des performances optimales.

APIUsage dans le projet
Animated.ValueValeur animable (position, opacité, scale…)
Animated.timing()Animation linéaire ou avec easing — Toasts, overlays
Animated.spring()Animation physique type ressort — Bottom sheets
Animated.sequence()Enchaîner des animations
Animated.parallel()Lancer des animations simultanément
Animated.loop()Répéter une animation en boucle
.interpolate()Transformer la valeur (ex: 0→1 devient '0deg'→'360deg')
Animated.ViewComposant View qui accepte les valeurs animées
useNativeDriver: trueExécution sur thread natif pour 60fps
 
// Exemple — Toast animé (utilisé dans Feed, Profile)
const opacity = new Animated.Value(0);

useEffect(() => {
  Animated.sequence([
    Animated.timing(opacity, { toValue: 1, duration: 300, useNativeDriver: true }),
    Animated.delay(2000),
    Animated.timing(opacity, { toValue: 0, duration: 300, useNativeDriver: true }),
  ]).start();
}, []);

Navigation — Expo Router

Expo Router utilise le système de fichiers pour définir les routes, exactement comme Next.js. Chaque fichier dans app/ devient une route navigable.

Structure des routes

app/
├── _layout.tsx      ← Layout racine : providers + AuthGuard + Tabs
├── index.tsx        ← Route "/" → Feed (onglet 1)
├── explore.tsx      ← Route "/explore" → Explore (onglet 2)
├── Reels.tsx        ← Route "/Reels" → Reels (onglet 3)
├── DirectMessages.tsx ← Route "/DirectMessages" → DMs (onglet 4)
├── Profile.tsx      ← Route "/Profile" → Profil (onglet 5)
├── Camera.tsx       ← Route "/Camera" → Caméra (poussée, hors tab)
└── Auth.tsx         ← Route "/Auth" → Login (redirection si non connecté)

Hooks de navigation

Hook / APIRôle
useRouter()Accès au router — push(), replace(), back()
useLocalSearchParams()Lire les paramètres de la route courante
useSegments()Segments actifs de l'URL (utilisé pour l'AuthGuard)
useFocusEffect()Code exécuté à chaque fois qu'un écran prend le focus
<Tabs>Navigation par onglets en bas de l'écran
<Link>Lien déclaratif vers une route

AuthGuard — Protection des routes

// app/_layout.tsx — Pattern de garde d'authentification
function AuthGuard({ children }) {
  const { user } = useAuth();
  const segments = useSegments();
  const router = useRouter();

  useEffect(() => {
    const inAuth = segments[0] === 'Auth';
    if (!user && !inAuth) router.replace('/Auth');
    if (user && inAuth)  router.replace('/');
  }, [user, segments]);

  return children;
}

AsyncStorage

Stockage clé-valeur persistant (équivalent de localStorage sur le web). Toutes les opérations sont asynchrones.

import AsyncStorage from '@react-native-async-storage/async-storage';

// Sauvegarder
await AsyncStorage.setItem('@instagram_user', JSON.stringify(user));
// Lire
const stored = await AsyncStorage.getItem('@instagram_user');
// Supprimer
await AsyncStorage.removeItem('@instagram_user');

// utils/api.ts — Auto-injection du token JWT
const apiGet = async<T>(path: string): Promise<T> => {
  const token = await AsyncStorage.getItem('token');
  const res = await fetch(`${API_URL}${path}`, {
    headers: { Authorization: `Bearer ${token}` }
  });
  if (res.status === 401) handleUnauthorized();
  return res.json();
};

Système de thème (Light / Dark)

Règle absolue du projet : jamais de couleurs en dur dans les composants. Toujours utiliser useTheme().

Tokens de couleur disponibles :
background card border text textSecondary primary surface overlay inputBg iconActive iconInactive tabBar storyRing like 
// Pattern correct — toujours injecter les couleurs dynamiquement
const { colors } = useTheme();
<View style={[styles.container, { backgroundColor: colors.background }]}>
  <Text style={[styles.title, { color: colors.text }]}>Bonjour</Text>
</View>
